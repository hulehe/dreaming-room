# 平行时空纪念与祝福窗

一块摆在客厅、纪念堂或庆典现场的竖屏相框。屏幕像一扇窗户，对着一间 3D 小屋。人不在时，屋里的数字人过日常；人走近后，数字人走到屏前微笑，再用这个人的声音对话。

用户能碰到三个界面：

1. 定制工作台：销售和礼仪师上传照片、录音和问卷，生成数字人。开发语言尚未选定。前期在 Ubuntu 26.04 上测试。
2. 安卓相框：产品本体。播放画面，采集语音，检测人走近和离开。
3. 观看页：打开同一个数字人，用于试用和异地观看。打开就进入走近之后的状态。前期是网页。

产品需求文档只有一份：`Documents/上层决策/产品/产品需求文档.md`。文档怎么读、部门怎么分工，见 `Documents/目录.md`。本文件只做介绍，不另写需求。
