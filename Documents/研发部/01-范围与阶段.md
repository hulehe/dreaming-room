# 范围与阶段

版本：v1.7 · 2026-11-14 21:23:31 · 批示 024

依据 PRD 第 1、2、5 节。

## 产品范围

一块商用高清安卓竖屏相框，OEM 外框，带传感与拾音。相框是产品本体，屏幕是一扇对着 3D 小屋的窗户。用户界面三个：定制工作台、安卓相框、观看页。观看页打开即进入走近之后的状态，没有走近感应和无人休眠，也不替代第 2 节的首年硬件费。定制工作台不规定网页，前期在 Ubuntu 26.04 上能测试即可。观看页前期是网页，在 PC 浏览器里测试，不考虑手机兼容。数字人在相框上有三种现场体验，再加一条合规边界：

| 体验 | PRD 依据 | 用户看到的结果 |
| :--- | :--- | :--- |
| 无人休眠期 | 第 1 节、第 4 节 | 人未靠近时，看到屋内日常，或息屏待机；此期间云端 GPU 不保持占用 |
| 走近唤醒期 | 第 1 节、第 3.2 节、第 4 节 | 检测到走近后，数字人放下手头动作，起身走到屏幕前并微笑 |
| 实时对话期 | 第 1 节、第 3.3 节 | 用人物声音和微表情做实时语音对话 |
| 健康告别 | 第 2 节 | 对话持续数分钟后，数字人自然道别并回屋休息。批示 020 另加拟人化互动的提醒、退出和深度合成标识；这些不代替数分钟道别 |

场景覆盖两类用途，能力是同一套，内容不同：温情追思与银发陪伴；喜庆礼赠、寿宴重逢、文旅非遗展厅。规格不把某一类场景做成另一套系统。

商业闭环保持 PRD 第 2 节的三段：首年软硬件打包、高定增值（3DGS 老家、高定服饰）、次年云端维护与按需推流订阅。计费、招商、招募不塞进渲染和对话实现。市场材料在 `Documents/市场部/`。本部门的 30 秒实拍是 Demo 成片。

## 阶段边界

时间以 PRD 第 5 节为准。前一阶段的交付物是后一阶段的输入，不提前把后一阶段的完成标准套到前一阶段。

### 第一阶段：单兵 Demo（第 1～2 周）

第一阶段交付两个软件：定制工作台，和观看页网页。定制工作台不规定网页。安卓相框不在本阶段。目标和交付物以 PRD 第 5 节表格里的第一阶段为准，这里只列名称：

1. 定制工作台。不规定网页和开发语言。在 Ubuntu 26.04 上能测试。含 2 套房间与服饰的切换，以及滑块控件。产品第一版必须的仍是 1 间房、1 套衣服；滑块和阶梯不是第一版必须功能
2. 本机上的走近与一轮对话
3. 观看页网页。打开即进入走近后的状态，用本机画面，不考虑手机
4. 30 秒实拍体验视频

演示角色使用虚构人物，或使用已有书面授权的样例。照片转人脸流水线、原声克隆流水线、云端按需推流、OEM 安卓联调、电子协议生产流程、观看页的手机兼容，属于后面的阶段。

「2 套房间 / 服饰」在本规格中读作：2 个可切换组合，每个组合含 1 个房间和 1 套服饰。若要改成别的数量，先改待定项 D5。

### 第二阶段：冷启动与组队（第 3～6 周）

研发侧没有新的功能清单，保持第一阶段 Demo 可被录制和演示。短视频发布、渠道反馈和招募材料的整理在市场部。招募人选由你定。

### 第三阶段：1.0 产品研发（第 2～4 个月）

交付物：

1. 照片转人脸、声音克隆的全自动流水线
2. 定制工作台在平板上使用，并达到 PRD 第 3.1 节的操作深度
3. 观看页补上手机兼容
4. 云端按需推流与 OEM 安卓相框联调

到本阶段，第 3、4 节的系统能力按 `04-分系统规格.md` 验收：Behavior Tree、感官氛围、接近感应、全双工 ASR → LLM → TTS → Audio2Face、5 秒过渡掩盖冷启动、无人超过 30 秒释放 GPU、直系亲属授权协议。

### 第四阶段：内测与上市（第 5～6 个月）

交付物：

1. 10～20 组种子家庭与合作门店试用，并按试用结果打磨
2. 合规协议与销售 SOP
3. 启动 B 端渠道招商放量

试用打磨只改已经写进 PRD 和本文件夹的行为。招商放量不产生新的技术模块，除非另写任务书并得到同意。市场侧的招商材料在 `Documents/市场部/`。

## 阶段对照

| 能力 | 第一阶段 | 第三阶段 1.0 | 第四阶段 |
| :--- | :--- | :--- | :--- |
| 定制工作台、滑块与 2 套切换 | 在 Ubuntu 26.04 上可操作，不规定网页，画面随房间和服饰变化 | 工作台在平板上使用，并带阶梯资产库。开发语言届时已定 | 按试用打磨 |
| 观看页 | PC 浏览器打开即进入走近后的状态，不考虑手机 | 补上手机兼容 | 按试用打磨 |
| 走近、微笑、对话、口型 | Demo 路径跑通，并进入 30 秒视频 | 传感器、全双工、Audio2Face | 按试用打磨 |
| 无人期生活感 | 视频中要出现 | 本地预渲染微动或息屏，GPU 释放 | 同 1.0 |
| 5 秒冷启动掩盖、30 秒释放 | 可在本机 UE5 里演示体验，不要求云端实例 | 安卓终端 + 云端 GPU 联调通过 | 同 1.0 |
| 照片转脸、声音克隆 | 不作为本阶段完成标准 | 全自动流水线 | 同 1.0 |
| 授权协议 | 演示角色为虚构或已授权样例 | 未授权不能生成定制数字人 | 协议与销售 SOP 定稿 |
| 健康告别 | 视频不要求演完数分钟 | 到达确认后的时长上限后道别回屋 | 同 1.0 |

市场部在各阶段同时出小视频和静态 PPT，规则见 `Documents/市场部/01-宣传规则.md`。

## 验收口径

每一阶段只按该阶段交付物验收。演示视频要能依次看出：屋内日常、走近后走到屏幕前微笑、开口问候并完成一轮对话且口型随语音变化。
