# 分系统规格

版本：v1.3 · 2026-11-14 16:29:19 · 批示 020

依据 PRD 第 3、4 节，并受本文件夹 `01-范围与阶段.md` 的阶段边界约束。第一阶段的完成标准见 `05-第一阶段任务书.md`。本节其余条款按第三阶段 1.0 验收，除非条目写明属于第一阶段。待定项见 `06-待定项.md`。

## 销售工作台

对象是线下销售与礼仪师。操作深度对齐「美图秀秀 + 模拟人生」：拖拽导入、滑块、档位选择、眼前能看到结果。界面不暴露 UE5、骨骼、材质等制作术语。

工作台包含四块：

1. **资料导入**：拖拽 1～3 张正面清晰照片、10～30 秒语音、问卷（口头禅、家庭关系、忌讳话题）。
2. **形象微调**：脸型胖瘦、皱纹深浅、眼神温和度、微笑弧度；年龄在「中年精神」与「晚年慈祥」之间切换。晚年状态提高白发比例并带微驼体态。白发与体态的具体幅度由该套 MetaHuman 资产表现，不在规格里写死百分比。
3. **声音试听**：语速、音调、方言浓重度；现场输入文字即可试听。
4. **阶梯选配**：服饰与房间按 PRD 的三档呈现。高定档是 3DGS 老家与照片贴图服装，作为增值项，不出现在第一阶段的两套组合里。

所见即所得：房间、服饰、年龄状态的变更要反映在预览上。某一五官或声音滑块若还没驱动到预览，界面保持该控件，并标明尚未接通，避免看起来已经生效。

形态是网页或桌面端，见 D11。第一阶段至少有一个本地可操作面板，能切换 2 套组合。

## 渲染与行为

底座是 UE5 MetaHuman。在场时具备呼吸起伏、自然眨眼、眼球微扫视。

Behavior Tree：

- `daily`：在摇椅、茶桌、窗边等交互点之间切换看书、喝茶、浇花、听音乐一类日常动作。环境可带雨声、风声。
- `approach`：放下手头动作，寻路走到摄像机前，微笑，进入倾听姿态。
- `listen` / `speak`：对话期的倾听与说话姿态。说话时脸部由 `DriveFace` 驱动。
- `goodbye`：道别，走回屋内休息。

感官氛围与房间绑定，包含雨声、风声、树叶声、暖色灯光的明暗起伏、背景音乐，并做空间音效。两套同时启用的房间要能听出、看出差别。第一阶段的精品房间若选用江南雨夜书房，则该套必须带雨声。

第一阶段的实时画面来自本机 UE5。第三阶段的实时画面来自云端 UE5，经 Pixel Streaming 推到相框。推流内容是画面；语音链路的采集在终端，角色语音与环境声随最终混音进入用户听到的输出。具体混音点在 1.0 联调任务里确定，见 D8，避免在供应商未定的情况下写死拓扑。

## 对话与感知

接近感应是摄像头人脸距离，或毫米波雷达。产品默认见 D4。检测到走近进入过渡掩盖；检测到离开并超过 30 秒进入离场释放。

1.0 语音链是全双工：

1. ASR：普通话与常见地方方言。方言枚举见 D7。
2. LLM：回答符合该人物身份，材料只来自 FrameProfile。
3. TTS：低延迟，音色与语气按该人物声音输出。`custom` 档案使用克隆声音。
4. Audio2Face：嘴型、脸颊、眉眼随这段语音变化。

第一阶段不把全自动克隆流水线当作完成标准。Demo 使用为虚构角色准备的声音，完成一次问候和一轮你来我往，并且口型随该段语音动。全双工、方言覆盖面、Audio2Face 的情绪联动在 1.0 验收。

对话到达 D2 确认的时长后，只能走健康告别，不提供「再延长一轮」的产品开关。PRD 把这条写成交互边界。批示 020 的法定提醒和退出是另一组义务，不把数分钟改成 2 小时。

## 终端与省算力

安卓相框负责三件事：播放画面、采集语音、触发传感器。UE5 与 AI 推理放在云端 GPU。

省算力规则：

- 本地休眠期间不占云端 GPU。终端播放 `ShowIdle`。
- `ApproachDetected` 到达的同一时刻，终端执行 `PlayTransition`，调度器启动 GPU。
- 实时帧就绪后执行 `StartLiveView`，对齐过渡片最后一帧。
- `PersonAbsent` 且 `absentForMs >= 30000` 时执行 `StopLiveView`，原因 `absent_30s`，并释放实例。

竖屏是确定的。具体分辨率等 OEM 机型确定后写入待定项 D12。第一阶段不采购相框。

## 合规

定制数字人只接受本人或直系亲属申请。系统在生成 `custom` 档案前记录肖像授权、声音授权和电子协议。关系名单见 D10，确认前不放行 `custom`。

第一阶段的对外素材只使用 `fictional` 或 `licensed_sample`。样例若来自真人，任务书中要能指出授权记录的位置。

忌讳话题进入 LLM 的人物约束。回答时不顺着忌讳话题展开的具体说法见 D9。
