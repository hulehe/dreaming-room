# 模块与接口

版本：v0.1 · 2026-11-13 · 批示 005

依据 PRD 第 3、4 节。模块按职责拆开。接口字段用英文名，语义以中文为准。你确认本文件前，接口不视为冻结。

## 模块

| 模块 | 职责 | 第一阶段 | 第三阶段 |
| :--- | :--- | :--- | :--- |
| SalesWorkbench | 资料导入、滑块、试听、服饰与房间选配 | 滑块面板原型 | 傻瓜工作台 |
| ComplianceGate | 本人或直系亲属身份核验，肖像与声音授权 | 仅允许虚构或已授权样例 | 未通过则不能生成定制数字人 |
| FrameProfile | 一份相框所绑定的人物、声音、问卷、服饰、房间 | 本地配置即可驱动 Demo | 工作台保存，终端与渲染读取同一份 |
| AndroidFrame | 播放、拾音、传感器；不做 UE5 渲染 | 用拍摄用的屏幕代替 | OEM 竖屏相框 |
| SessionOrchestrator | 按走近启动云端，按离开释放 | 本机直接运行 UE5，不要求调度器 | 必须 |
| LocalPlayback | 日常循环与 5 秒过渡片 | 可在成片中体现 | 必须在终端本地播放 |
| Ue5Runtime | MetaHuman、Behavior Tree、氛围、Pixel Streaming 画面 | 本机实时画面 | 云端 GPU 实例 |
| VoicePipeline | ASR、LLM、TTS、Audio2Face | Demo 跑通问候和一轮对话，口型跟语音 | 全双工与原声克隆流水线 |

第一阶段允许用本机 UE5 窗口代替 AndroidFrame + Pixel Streaming。第三阶段验收时，渲染在云端，终端只做显示、拾音和传感。

## FrameProfile

一份配置对应一框一位数字人。

| 字段 | 类型 | 约束 | 依据 |
| :--- | :--- | :--- | :--- |
| `profileId` | string | 唯一 | 实施需要 |
| `characterOrigin` | `fictional` \| `licensed_sample` \| `custom` | `custom` 必须先通过 ComplianceGate | 第 2 节 |
| `photos` | 文件列表 | `custom` 时 1～3 张正面清晰照片 | 第 3.1 节 |
| `voiceSample` | 音频 | `custom` 时 10～30 秒 | 第 3.1 节 |
| `catchphrases` | string[] | 口头禅 | 第 3.1 节 |
| `familyRelations` | string | 家庭关系 | 第 3.1 节 |
| `tabooTopics` | string[] | 忌讳话题 | 第 3.1 节 |
| `face.fullness` | number | 脸型胖瘦，范围见 D6 | 第 3.1 节 |
| `face.wrinkle` | number | 皱纹深浅，范围见 D6 | 第 3.1 节 |
| `face.gazeWarmth` | number | 眼神温和度，范围见 D6 | 第 3.1 节 |
| `face.smileArc` | number | 微笑弧度，范围见 D6 | 第 3.1 节 |
| `ageState` | `midlife` \| `elderly` | 中年精神 / 晚年慈祥；晚年匹配更高白发比例与微驼体态 | 第 3.1 节 |
| `voice.rate` | number | 语速，范围见 D6 | 第 3.1 节 |
| `voice.pitch` | number | 音调，范围见 D6 | 第 3.1 节 |
| `voice.dialectStrength` | number | 方言口音浓重度，范围见 D6 | 第 3.1 节 |
| `voice.dialectId` | string | 具体方言枚举未定，见 D7 | 第 3.3 节 |
| `costumeId` | string | 必须属于服饰库某一档 | 第 3.1 节 |
| `roomId` | string | 必须属于房间库某一档 | 第 3.1 节 |

服饰档位：基础棉麻日常装；精致真丝唐装、定制西装、复古旗袍；照片贴图定制服装。  
房间档位：基础阳光木屋、简约客厅；精品江南雨夜书房、海景花房、四合院；尊享 3DGS 实景老家。

第一阶段只启用 2 个组合，见 D5。其余档位留在资产库定义里，1.0 再开放选配。

## 终端事件（AndroidFrame → SessionOrchestrator）

| 事件 | 字段 | 语义 |
| :--- | :--- | :--- |
| `ApproachDetected` | `deviceId`, `at`, `sensor` | 有人走近。`sensor` 为 `camera` 或 `mmwave` |
| `PersonAbsent` | `deviceId`, `absentForMs` | 无人持续时长。`absentForMs >= 30000` 时调度器释放会话 |
| `MicAudio` | `sessionId`, `seq`, `format`, `payload` | 会话期间的拾音。编码格式 1.0 联调时确定，见 D8 |

第一阶段拍摄若需要人工触发走近，可使用 `sensor = manual`。该值只存在于 Demo 拍摄路径。1.0 产品路径只有 `camera` 与 `mmwave`。用哪一种作为产品默认，见 D4。

## 会话指令（SessionOrchestrator → AndroidFrame）

| 指令 | 字段 | 语义 |
| :--- | :--- | :--- |
| `ShowIdle` | `mode`, `assetId` | `mode` 为 `prerendered_loop` 或 `screen_off` |
| `PlayTransition` | `assetId`, `durationMs` | `durationMs` 为 5000。终端立即播放，与云端冷启动并行 |
| `StartLiveView` | `transport`, `signalingUrl` | `transport` 为 `pixel_streaming`。对齐过渡片最后一帧后显示 |
| `StopLiveView` | `reason` | `reason` 为 `absent_30s` 或 `startup_failed` |

## 工作台动作

| 动作 | 结果 |
| :--- | :--- |
| `ImportSources` | 写入照片、10～30 秒录音、问卷三项 |
| `SaveProfile` | 保存 FrameProfile。`characterOrigin = custom` 时 ComplianceGate 未通过则拒绝保存 |
| `PreviewVoice` | 输入一段文字，按当前语速、音调、方言浓重度试听 |
| `ApplyPreview` | 预览中的房间、服饰、年龄状态与当前选择一致 |

## 渲染入站（发给 Ue5Runtime）

| 动作 | 语义 |
| :--- | :--- |
| `ApplyLook` | 应用服饰、房间、年龄状态和已接通的五官滑块 |
| `SetBehavior` | `daily`、`approach`、`listen`、`speak`、`goodbye` |
| `DriveFace` | 用当前语音驱动口型与表情。1.0 为 Audio2Face |
| `SetAmbience` | 按房间播放对应的环境声、灯光和背景音乐 |

`daily` 对应屋内休闲点之间的日常动作。`approach` 对应寻路到摄像机前并微笑。`goodbye` 对应道别后走回屋内。

## 对话回合（VoicePipeline）

一次用户发言经过 ASR，得到文本。LLM 只依据该 FrameProfile 的生平记忆、性格、口头禅、家庭关系、忌讳话题和年龄状态生成回答。TTS 输出语音。Audio2Face 按这段语音驱动嘴型、脸颊和眉眼。

忌讳话题的具体岔开方式见 D9。方言清单见 D7。模型供应商见 D8。规格不写死某一家 API。

## 合规记录

`custom` 档案在生成数字人之前要有一条记录：

| 字段 | 约束 |
| :--- | :--- |
| `applicantRelation` | 属于已确认的关系枚举，见 D10 |
| `portraitConsent` | 已接受肖像授权 |
| `voiceConsent` | 已接受声音授权 |
| `agreementAccepted` | 已接受电子协议 |

关系枚举确认前，不实现 `custom` 档案的放行逻辑。第一阶段只用 `fictional` 或 `licensed_sample`。
