# 依赖

批示 032、034。单独使用的软件写在这里。库不逐条抄入，用该语言的管理工具锁定。

要装的单独软件先写成待批示，写明名称、具体版本、来源和用途。需要账号或许可协议才能取得的，你同意后由你安装，再把可执行文件路径交给研发写入本文件。开源的，你同意后由研发安装，并把版本和路径写入本文件。同意之前不安装，不调用。

库的锁文件放在对应的 `Code/` 子目录里并提交。不提交依赖目录、虚拟环境和引擎本体，也不提交 UE5 的 `Intermediate`、`Saved`、`DerivedDataCache`、`Binaries`。

- Python 的库只用 uv。工程里提交 `pyproject.toml` 和 `uv.lock`，不提交 `.venv`。uv 本身是单独软件，第一次用 Python 时写入本文件。
- 其他语言在选定该语言时同时写明它的管理工具，并记入本文件。选定之前不用库。
- UE 工程自带的插件按 UE 的方式启用。要单独安装的外部插件写入本文件。
