# AI 3D 互动数字人智能相框（平行时空纪念与祝福窗）项目需求文档（PRD）

版本：v1.0 · 2026-11-13 14:34:48 · 批示 017

## 1. 项目概述与核心定位
* **产品名称**：AI 3D 互动数字人智能相框（平行时空纪念与祝福窗）
* **核心产品形态**：一块摆放在家庭客厅、纪念堂或庆典现场的商用高清安卓竖屏相框（OEM 定制外框），内置传感与拾音模块，如同一扇通往“平行时空温馨小屋”的立体窗户。
* **核心交互体验**：
  * **无人休眠期**：数字人在精致的 3D 屋内自然生活（如看书、喝茶、浇花、听音乐、听雨声风声），保持日常状态循环。
  * **走近唤醒期**：传感器（摄像头/毫米波雷达）检测到家属或宾客走近屏幕时，数字人放下手中动作，起身走到屏幕前并露出微笑。
  * **实时对话期**：通过本地拾音与云端 AI 大模型，用克隆的原声及自然微表情与用户进行实时、有温度的语音对话。
* **应用场景扩展**：
  * **温情追思与银发陪伴**：纪念逝去亲人、异地亲情陪伴。
  * **喜庆礼赠与庆典祝福**：高端婚庆隔空送祝福（高龄祖辈/海外亲友）、寿宴与年轻时的自己重逢、文旅非遗大师交互展厅。

## 2. 商业模式与业务闭环（B2B2C）
* **目标渠道（B端）**：传统殡葬公墓与礼仪公司、高端康养机构、连锁婚庆策划公司、高端宴会厅、商业展厅。
* **终端用户（C端）**：有情感纪念需求或喜庆礼赠需求的中高收入家庭。
* **盈利结构**：
  1. **软硬件首年打包供货**：向 B 端渠道收取硬件相框 + 首次数字人及房间定制费（支持房间与服饰从一般到高级的阶梯定价）。
  2. **高定增值服务**：3DGS 实景老家扫描复刻、专属高定服饰建模。
  3. **次年云端算力续费**：按年向 C 端家庭收取低门槛的云端空间维护与按需推流订阅费。
* **合规与风控要求**：
  * 系统强制内置《直系亲属身份核验与肖像/声音授权电子协议》，仅限本人或直系亲属申请定制，从源头规避肖像权与伦理风险。
  * 设定对话时长与健康告别的交互边界（例如对话数分钟后数字人自然道别回屋休息），避免用户过度沉迷。

## 3. 核心功能需求清单

### 3.1 销售端：傻瓜式定制工作台（前端网页 / 桌面端）
面向不懂 3D 技术的线下真人销售与礼仪师，界面需做到“美图秀秀 + 模拟人生”级别的极简操作：
* **一键资料导入**：支持拖拽上传 1~3 张正面清晰照片、10~30 秒语音录音，以及生平性格问卷（口头禅、家庭关系、忌讳话题）。
* **可视化滑块微调（所见即所得）**：
  * **五官与神韵调节**：脸型胖瘦、皱纹深浅、眼神温和度、微笑弧度。
  * **年龄状态切换**：一键切换中年精神状态或晚年慈祥状态（自动匹配白发比例与微驼体态）。
  * **声音与方言调节**：语速快慢、音调高低、方言口音浓重度，支持现场输入文字实时试听。
* **阶梯式资产选配（一般到高级）**：
  * **服饰库**：基础棉麻日常装 → 精致真丝唐装 / 定制西装 / 复古旗袍 → 照片贴图定制服装。
  * **房间场景库**：基础阳光木屋 / 简约客厅 → 精品江南雨夜书房 / 海景花房 / 四合院 → 尊享 3DGS 实景老家扫描复刻。

### 3.2 渲染与交互端：UE5 平行小屋引擎（后台运行）
* **超写实数字人底座**：基于 Unreal Engine 5（MetaHuman）构建，支持呼吸起伏、自然眨眼、眼球微扫视等基础微动作，消除“塑料感”与“恐怖谷效应”。
* **智能行为树（Behavior Tree）**：
  * 无人状态：在屋内多个交互点（摇椅、茶桌、窗边）随机切换日常休闲动作。
  * 唤醒状态：接收传感器触发信号后，自动寻路走至摄像机前，切换为倾听与对话姿态。
* **感官环境氛围系统**：支持雨声、风声、树叶莎莎声、暖色灯光呼吸起伏及背景音乐的空间音效联动。

### 3.3 AI 对话与感知闭环
* **接近感应触发**：通过摄像头人脸距离检测或毫米波雷达识别用户走近与离开。
* **全双工语音交互链**：
  * **ASR（语音识别）**：精准识别普通话及常见地方方言。
  * **LLM（角色扮演大脑）**：结合生平记忆库与性格设定生成符合人物身份的回答。
  * **TTS（原声克隆）**：低延迟合成高度还原音色与语气的语音。
  * **Audio2Face（表情驱动）**：根据语音情绪实时生成嘴型、脸颊肌肉及眉眼联动表情。

## 4. 系统技术架构与成本优化设计
* **终端与云端分离架构**：
  * **安卓平板终端**：仅作为轻量级显示器与采集器，负责播放画面、采集语音和触发传感器，彻底摆脱本地高算力硬件依赖。
  * **云端 GPU 服务器**：运行 UE5 渲染与 AI 推理，通过像素流送（Pixel Streaming）将实时高清画面推流至平板。
* **云端“按需唤醒”省算力机制**：
  * **休眠零成本**：无人靠近时，云端 GPU 实例释放或休眠，平板显示低功耗静态微动画面或息屏待机。
  * **无缝过场掩盖启动延迟**：检测到人走近的瞬间，平板本地立即播放 5 秒预渲染过渡视频（数字人放下茶杯起身走来）；云端 GPU 在这 5 秒内完成冷启动并无缝接管实时画面。
  * **离开自动释放**：检测无人超过 30 秒后自动断开云端算力，最大化压缩单台设备的月度算力成本。
