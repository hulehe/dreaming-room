## 材料纪律

- 能力声明要么引用 PRD 的原意，要么引用已经完成的阶段交付物。
- 尚未完成的能力只写计划所在的阶段，不写成已经可以交付。
- 演示人物使用虚构角色或已授权样例，画面上能看出这是演示。
- 写明定制边界：本人或直系亲属、肖像与声音授权、对话数分钟后的健康告别，以及批示 020 写入 PRD 的拟人化互动提醒、退出和深度合成标识。关系枚举以 D10 确认结果为准；D10 未确认时，宣传册只复述 PRD 原文「本人或直系亲属」，不自行列举配偶等关系。
- 价格只复述 PRD 的收费结构：首年软硬件打包、高定增值、次年云端订阅。PRD 没有金额，宣传册不写价格数字。
- 不编造客户、引言、播放量、意向订单和调研样本。

## 市场调查要回答的问题

调查只围绕下面这些问题。阶段不同，能使用的证据不同。

1. 上面五类渠道里，谁会把相框放进现有服务。
2. 首年「硬件 + 首次数字人与房间定制」是否符合他们的采购方式。
3. 服饰与房间的阶梯（一般到高级，再到 3DGS 和高定服饰）是否分得清。
4. 追思陪伴与喜庆祝福，渠道是否接受为同一产品的两种内容。
5. 直系亲属授权和健康告别，是让渠道放心，还是挡住成交。
6. C 端对次年云端维护与按需推流订阅的接受度。这里不假设具体价格。

结论分成两列：材料里的原话或公开信息；据此作出的推断。推断不能单独变成产品需求。

## 静态 PPT 的页结构

每一版静态 PPT 使用同一骨架，缺的事实就少一页，不补故事。

1. 产品是什么：相框是本体，摆在客厅、纪念堂或庆典现场，一扇对着 3D 小屋的窗户。观看页打开同一个数字人，一打开就进入走近之后的状态；不写走近感应和无人休眠。前期这条是 PC 上的网页，手机兼容留到后面。
2. 三种体验：无人时的屋内日常、走近后走到屏前微笑、实时对话。合规页写健康告别。
3. 两种内容：追思陪伴，喜庆与寿宴、非遗展陈。
4. 给谁用：上表中的 B 端与 C 端。
5. 怎么收费：三段结构，无金额。
6. 销售如何定制：第一版是照片、短录音、问卷，以及 1 间房、1 套衣服。滑块、服饰与房间阶梯留在后面。只写本阶段已经能演示的操作。
7. 信任边界：直系亲属授权、肖像与声音授权。
8. 本阶段进度：已完成的交付物，以及下一阶段的 PRD 目标。
